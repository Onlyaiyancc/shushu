# Distilled Rulebook

This rulebook turns checked local materials into reusable judgment rules. It is not a claim that the full corpus has been learned. Each rule should be treated as a working doctrine with a source anchor, reliability label, and practical boundary.

Reliability labels follow `reading-protocol.md`: Strong, Medium, Weak, or Version issue.

## Conflict Resolution

1. Use the question's branch first. Do not answer a 六爻 question with 八字 rules unless the user asks to combine methods.
2. Judge the main tendency before timing.
3. If 用神 is damaged but a secondary sign is pleasant, do not give a pleasant verdict.
4. If a bad sign is weak, static, empty, or restrained, do not exaggerate fear.
5. If rules conflict, prefer the rule with stronger source support and closer domain fit.
6. For daily matters, convert the final judgment into one small action, one avoidance, and one fallback.
