# Shushu Skill

This repository contains a Codex skill for Chinese shushu research and daily low-stakes interpretation.

The skill is named `shushu` and covers traditional Chinese fate and divination systems such as 八字、子平、六爻、易占、相术、星命、风水、择日、奇门、六壬、太乙.

## Contents

- `skills/shushu/SKILL.md`: skill entrypoint.
- `skills/shushu/references/`: source map, method notes, daily-use guidance, reading protocol, and distilled rulebook.
- `生成简体学习版.py`: converts local HTML/TXT sources into simplified Chinese study texts.
- `下载三命通会维基卷页.py`: downloads Wikisource pages for《三命通会》卷01-12.
- `学习日志.md`: learning log.
- `全库学习进度表.md`: corpus coverage and next reading targets.
- `简体学习版优先阅读清单.md`: simplified-study reading list.

## Corpus Note

The downloaded source corpus is intentionally not tracked in Git. It lives locally under `E:\Thing\Fortune\资料库` and can include large scans, generated simplified study copies, and externally sourced files.

The rulebook records which materials were actually checked. It should not be read as a claim that the entire corpus has been fully learned.
