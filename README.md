# Shushu Skill

This repository contains a Codex skill for Chinese shushu research and daily low-stakes interpretation.

The skill is named `shushu` and covers traditional Chinese fate and divination systems such as 八字、子平、六爻、易占、相术、星命、风水、择日、奇门、六壬、太乙.

## Contents

- `SKILL.md`: skill entrypoint.
- `references/`: source map, method notes, daily-use guidance, reading protocol, and distilled rulebook.

## Corpus Note

The downloaded source corpus is intentionally not tracked in this repository. The skill expects a local study corpus when available, but the repository itself only contains the reusable skill instructions and distilled references.

The rulebook records which materials were actually checked. It should not be read as a claim that the entire corpus has been fully learned.

## Install

Install this skill by copying the repository folder into your Codex skills directory as `shushu`, or install it from GitHub with the Codex skill installer when available.
