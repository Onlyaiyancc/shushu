# Reading Protocol

Use this when distilling doctrine from local scans and web texts.

## Corpus Handling

1. Start with local text/HTML for retrieval.
2. If OCR is garbled, open the corresponding PDF or another edition.
3. Record the exact local path and title.
4. Do not merge original text, later commentary, and modern explanation without labeling them.
5. Prefer repeated ideas across independent texts over isolated maxims.

## Distillation Template

For each doctrine, capture:

- Term: Chinese term and literal translation if helpful.
- Branch: 八字、卜筮、相术、堪舆、星命、三式, etc.
- Definition: concise functional meaning.
- Rule: how it is used in judgment.
- Conditions: when it applies and when it does not.
- Source support: local file/title and passage locator when available.
- Interpretation: modern plain-language explanation.
- Risk of misuse: common overextension or contradiction.

## Reliability Labels

Use these labels in summaries:

- **Strong**: appears in core texts or multiple independent sources and is internally consistent.
- **Medium**: appears in one important text or lineage but needs context.
- **Weak**: isolated, OCR-uncertain, late, or contradicted by other sources.
- **Version issue**: source title, authorship, or text layer is uncertain.

## Quotation Rules

Quote short passages only when useful. Keep quotations brief and identify the source. If the passage comes from OCR, mark it as OCR-derived unless confirmed against the scan.

## Output Style

Use tables for doctrine maps, but use prose for actual readings. A good distillation should help the next agent make a judgment, not merely collect sayings.
