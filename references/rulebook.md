# Distilled Rulebook

This rulebook turns checked local materials into reusable judgment rules. It is not a claim that the full corpus has been learned. Each rule should be treated as a working doctrine with a source anchor, reliability label, and practical boundary.

Reliability labels follow `reading-protocol.md`: Strong, Medium, Weak, or Version issue.

3. If 用神 is damaged but a secondary sign is pleasant, do not give a pleasant verdict.
